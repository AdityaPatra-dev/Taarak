## `backend/` — standalone secondary Dart package, not part of the Flutter app build

`backend/lib/src/account.dart`, `backend/lib/src/taarak_backend.dart`, plus its own `backend/test/`. A `shelf`/`shelf_router` HTTP stub, explicitly self-described in its own `pubspec.yaml` as *"Local backend stub ... not a production service"* and, per the main app's `pubspec.yaml` comment, no longer used by the running app (superseded by the real Firebase backend). See `docs/modules/core_infrastructure.md` and `02_TECH_STACK.md`.
